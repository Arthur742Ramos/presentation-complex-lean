## Local reproduction

Run these from the repository root with the pinned toolchain available:

1. Obtain pinned Mathlib dependencies: `lake exe cache get`.
2. Check the shipped generated bytes without modifying them:
   `python3 scripts/generate_standalone.py --check`.
   After intentional modular edits, regenerate with
   `python3 scripts/generate_standalone.py`, review, then recheck.
3. Run `python3 scripts/audit_sources.py` for the source-only generation,
   admission, configuration, and helper-name audit. This is not a Lean verdict.
4. Run `lake build` for the complete package. On constrained hosts,
   `python3 scripts/build_lake_serial.py` runs serial normal Lake builds followed
   by the aggregate build.
5. Run `python3 scripts/build_sources.py` to replay every shipped modular source,
   both standalones, and the generated audit harness.
6. Print the complete target and transitive axiom audit:
   `lake env lean -j1 -M6144 reports/AuditSolution.lean`.

The intended Challenge holes are `PresentationComplex.presentation_complex` and
`PresentationComplex.every_group_fundamental_group`. Modular proofs and Solution
must contain no admissions or custom mathematical axioms. The allowed standard
axioms are `propext`, `Classical.choice`, and `Quot.sound`.

## Exports and independent checks

Set `LEAN_PREFIX` to the exact installed distribution, including
`src/lean/lake/Lake/CLI/Check.lean`. The local runner records stages separately and
binds results to source and export hashes:

- Prepare metadata:
  `python3 scripts/derive_verification_metadata.py --lean-prefix "$LEAN_PREFIX"`
- Run selected stages:
  `python3 scripts/verify_local.py --lean-prefix "$LEAN_PREFIX" --stages static source_replay compile axioms exports kernels comparator`

Independent checker binaries must already be available; an absent binary is a
blocked check, not a pass. Use only the supported environment and sandbox. The
prior checkpoint's local sandboxed Comparator was blocked at kernel launch by
NETLINK_ROUTE namespace creation. Its direct kernel passes and sandbox blocker
are historical results, not verdicts for new bytes.

Freeze and review the exact source before treating results as final. Generation,
a focused compilation, a full Lake build, every-source replay, transitive axiom
audit, direct kernel checks, and full Comparator are distinct gates. None
substitutes for an unperformed stage.

Official hosted full verification, trusted statement rendering, and registry
intake are separate procedures. They have not run for this repair; no submission
or acceptance is claimed. This document does not authorize them.
