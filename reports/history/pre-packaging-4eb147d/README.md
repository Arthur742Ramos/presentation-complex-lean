# Historical evidence: pre-packaging checkpoint

This directory preserves all 33 tracked files formerly under `reports/` at
public source checkpoint `4eb147db742945df1da36be923c346b1d82a1304`, byte-for-byte.
This README is the only added explanatory file in the snapshot.

**Historical evidence only.** The checkpoint predates the explicit CW cell-index
requirements in `completeStatement`, the second independent Challenge target,
and the construction-only every-group split. Its pass records and 83-module
counts do not verify the revised 84-module package.

Original path references, absolute local paths, timestamps, status wording, and
hashes are intentionally unchanged. Relative links in these frozen documents
refer to their original repository locations; consult Git history at the full
checkpoint above. Different reports describe different earlier stages, so each
must be interpreted against its own recorded inputs.

Ten script-managed metadata/audit files additionally keep active paths under
`reports/`; copies here preserve their old bytes before regeneration. Historical
reports/logs have moved here, while any logs already changed by a new run remain
untouched at their active paths. No file here is a current build input or a new
verification verdict.
