# Fundamental groups of arbitrary presentation complexes

The complete arbitrary presentation-complex theorem compiles on the pinned toolchain.
Whole-source replay, standalone and independent kernel checks, publication, and
official hosted verification are still pending at this checkpoint.

Target: for every generator type S, relator-index type R in an independent universe,
and family r : R → FreeGroup S, construct the genuine weak-topology bouquet and
complex-disk adjunction, an ordinary Mathlib CW structure with no cells above
2 dimensions, and an inclusion- and generator-compatible ordinary path-based
fundamental-group equivalence with FreeGroup S modulo the normal closure of r.
The intended consequence realizes every group as the fundamental group of a
genuine connected CW complex of dimension at most 2.
The every-group construction has an actual indexed two-cell as well as no
higher cells, so its CW structure is two-dimensional.

No finite/countable constraint, CW oracle, assumed generator identification,
sorry, or custom axiom is accepted in the final theorem.
